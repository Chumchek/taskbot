# TaskBot

Telegram-бот для управления микрозаданиями и выплатами в UAH.

---

## Команды пользователя

### `/start`
Запускает бота. Если пользователь не зарегистрирован — запускает процесс регистрации (Binance ID и/или номер карты). После отправки заявки ожидает одобрения администратора.

После одобрения открывает главное меню с разделами:
- **Задания** — список доступных заданий
- **Мои задания** — активные и выполненные задания
- **Мои отчёты** — история отправленных отчётов
- **Баланс** — текущий баланс и статус выплаты

---

## Функционал пользователя

### Задания
- Просмотр списка активных заданий с ценой и дедлайном
- Взятие задания (атомарное уменьшение слотов)
- Просмотр деталей задания (описание, ссылка, медиафайлы)
- Дедлайн на выполнение — задаётся администратором при создании (в часах); по истечении задание автоматически снимается

### Отчёты
- Отправка отчёта по взятому заданию — фото и/или видео
- Возможность прикрепить несколько файлов
- Статусы отчёта: ожидает проверки / одобрен / отклонён
- При одобрении — автоматическое начисление суммы на баланс

### Баланс и выплаты
- Просмотр текущего баланса в UAH
- Запрос на выплату доступен при балансе ≥ 200 UAH
- Выплата производится на карту или Binance ID, указанные при регистрации

## Команды администратора

> Доступны только пользователям из `ADMIN_IDS` или с флагом `is_admin` в базе данных.

### `/admin`
Открывает панель администратора с разделами:
- **Пользователи** — заявки на регистрацию
- **Задания** — управление заданиями
- **Отчёты** — проверка отчётов пользователей
- **Выплаты** — очередь на выплату

### `/promote <telegram_id>`
Выдаёт права администратора пользователю по его Telegram ID.

```
/promote 123456789
```

### `/ban <telegram_id>`
Блокирует пользователя. Доступ к боту немедленно закрывается, пользователь получает уведомление.

```
/ban 123456789
```

### `/unban <telegram_id>`
Снимает блокировку. Статус пользователя меняется на «одобрен», пользователь получает уведомление о восстановлении доступа.

```
/unban 123456789
```

## Функционал администратора

### Заявки на регистрацию
- При регистрации нового пользователя все администраторы получают уведомление с кнопками **Одобрить / Отклонить**
- После решения одного администратора кнопки у остальных автоматически исчезают
- Пользователь получает уведомление о результате

### Управление заданиями
- Создание задания: название, описание (опционально), ссылка, цена в UAH, количество слотов, дедлайн выполнения и срок жизни задания
- Прикрепление медиафайлов к заданию (фото/видео)
- Включение / отключение задания
- Удаление задания

### Проверка отчётов
- Просмотр отчётов со статусом «ожидает проверки»
- Одобрение — начисляет баланс пользователю автоматически
- Отклонение с комментарием — пользователь получает причину отказа

### Выплаты
- Очередь пользователей с балансом ≥ 200 UAH
- Просмотр платёжных данных (замаскированная карта / Binance ID)
- Подтверждение выплаты с пометкой «оплачено»

---

## Статусы пользователя

| Статус | Описание |
|--------|----------|
| `pending` | Заявка отправлена, ожидает одобрения |
| `approved` | Доступ разрешён |
| `rejected` | Заявка на регистрацию отклонена |
| `banned` | Заблокирован администратором |

---

## Переменные окружения

| Переменная | Обязательная | Описание |
|------------|-------------|----------|
| `BOT_TOKEN` | да | Токен Telegram-бота |
| `DATABASE_URL` | да | Строка подключения к PostgreSQL |
| `ENCRYPTION_KEY` | да | 64 hex-символа (шифрование номеров карт) |
| `ADMIN_IDS` | да | Telegram ID администраторов через запятую |
| `R2_ACCOUNT_ID` | да | Cloudflare R2 |
| `R2_ACCESS_KEY_ID` | да | Cloudflare R2 |
| `R2_SECRET_ACCESS_KEY` | да | Cloudflare R2 |
| `R2_BUCKET_NAME` | да | Cloudflare R2 |
| `WEBHOOK_URL` | нет | Если задан — бот работает в режиме вебхука; иначе — long-polling |
| `PORT` | нет | Порт для вебхука (по умолчанию 3000) |
